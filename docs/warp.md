# 控制网格局部形变

棱版支持由控制网格驱动的局部形变(warp):同一枚含曲线和镂空的图形只在指定区域内改变外形,区域外保持原状。形变表达保存在稿本 JSON 中,随修订、快照与封包一起移交;旧仿射稿不含 warp 字段,渲染结果逐字节不变。

## 表达

形变挂在形状上,作用于形状局部坐标(仿射 transform 之前):

```json
"warp": {
  "origin": {"x": 100, "y": 40},
  "step": {"x": 20, "y": 20},
  "cols": 4,
  "rows": 4,
  "gradient_space": "material",
  "points": [ {"x": 100, "y": 40}, ... ]
}
```

- 网格覆盖矩形 `origin .. origin + step*(cols,rows)`,每边 1..16 格。
- `points` 按行主序给出 `(rows+1)*(cols+1)` 个节点的位移后位置:节点 (i,j) 的静止位置是 `origin + (i*step.x, j*step.y)`,移动目标是 `points[j*(cols+1)+i]`。
- 映射规则:矩形内每格双线性插值,矩形外恒等。节点不移动即整格不变,因此可以只让徽记局部鼓起或拉弯。
- `gradient_space` 省略时为 `material`。

## 准入诊断(确认前指出)

稿本在创建、修订、封包导入与恢复重编译时经过同一编译准入。下列形变缺陷以 400 拒绝,稿本历史不变:

| 诊断 | 条件 |
|---|---|
| 边界节点必须钉住 | 边界节点偏离静止位置超过 1e-9,区域内外无法无缝相接 |
| 节点不得离开区域 | 内部节点越出网格矩形(容差 1e-9),材料会侵入区域外 |
| 折叠 | 任一网格角点的归一化雅可比行列式 ≤ 1e-9。双线性映射的 det J 是双线性函数,极值必在角点,因此角点检查对整格是精确的 |
| 轮廓翻转 | 形变后轮廓有向面积变号 |
| 轮廓坍缩 | 形变后轮廓面积 < 1e-9,或不足原面积的 1e-3(镂空被挤没) |
| 轮廓穿越 | 轮廓间包含关系改变(镂空被拖出本体) |

钉住边界 + 节点约束在区域内 + 每格雅可比为正,三者共同保证映射是全平面同胚:接缝两侧共享节点不会裂开,轮廓包含关系拓扑保持。上面的轮廓检查是这一保证在浮点下的可观察见证,并对具体形状给出指名诊断。

## 渐变跟随

每个带形变的形状独立选择渐变取色空间,两种选择在 PNG 渲染中采样不同的点,不是只换轮廓:

- `material`(默认):渐变粘在材料上随形状变形。覆盖点 q 先经逆形变 W⁻¹(q) 回到静止位置再取色。
- `canvas`:渐变固定在原画布位置。直接在 q 取色,变形轮廓从静止渐变场上滑过。

实色笔刷不采样位置,两种选择等价。SVG 无法表达随材料变形的渐变:material 模式下导出的渐变轴端点按 W(from)、W(to)  warp 作为线性近似,等值线在区域内可能偏离;canvas 模式轴向不变、与 PNG 语义一致。PNG 始终是像素校样的权威结果。

## 精度范围

- 形变求值:float64 双线性,坐标误差在 1e-12 相对量级。
- 可编辑曲线:M/L/Q/C/Z 源稿是唯一事实;Q/C 仍按固定 16/24 段细分,随后对细分顶点施加分格双线性 warp。长直边先在网格线处切开,区域内再细分到不超过半个格宽,单形状细分顶点上限 65536。变形折线与真实变形曲线的偏差 ≤ 源细分偏差乘以形变 Lipschitz 常数,加每格双线性残差 |P11-P10-P01+P00|/16。
- PNG 与 SVG 共用同一份变形后顶点,几何零分歧;SVG 坐标按 %.9g 输出,单坐标相对误差 ≤ 5e-10。差异只剩浏览器侧覆盖率与渐变插值(既有约定)。
- 逆形变(材料取色)由格间行走加双线性求根给出,末位截断在格内;覆盖判定只使用前向变形路径,逆映射误差不影响轮廓。
- 渲染预算:带 material 渐变的变形形状每网格每采样点计 4 条边的逆映射开销,并入既有 1.6 亿边遍历上限。

## 移交

warp 是稿本 JSON 的一部分:修订摘要、状态快照与 `prism-plate-bundle-v1` 封包都原样携带,封包格式与摘要规则不变。导入与恢复会重新执行同一准入,折叠或镂空消失的形变在移交对端同样被拒绝。演示输入见 examples/warp-badge.json,端到端校验见 scripts/walkthrough.py 的 warp 流程(独立 Python 参照重算形变并核对实际 PNG/SVG)。
